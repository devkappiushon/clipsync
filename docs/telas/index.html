O nome é só para você reconhecer a máquina. A identidade é a chave criptográfica, impressão digital f3d7-ea9a-056e-51c3.

O que sincronizar

Move o cursor para outra máquina pelas bordas que você configurar. No Linux pede permissão de captura de entrada; no Windows não pede nada.
Envia o texto que você copiar aos pares autorizados e recebe deles. Desligado por padrão. Só texto nesta versão.

Teste

O teste pode alterar o clipboard por alguns segundos e restaura em seguida.
